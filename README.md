# AI Career Platform

A React-based career platform designed to help users manage their career profile and explore future AI-powered career features.

## Project Overview

This project is being built as a production-style React application with a focus on reusable components, authentication, protected routes, form validation, and maintainable frontend architecture.

The current version includes authentication and user profile management functionality.

## Features

### Authentication

* User login and signup
* Authentication state management using React Context API
* Persistent authentication state
* Logout functionality
* Protected routes for authenticated users

### User Profile

* User profile page
* Profile information management
* Form validation using React Hook Form and Yup
* Reusable form components
* Loading/submission state handling

### Application Structure

* Reusable React components
* Custom React hooks
* Context-based state management
* Protected routing
* Service layer for API communication
* Centralized validation utilities
* Theme configuration

## Tech Stack

## Running the Project Locally

Clone the repository:

git clone https://github.com/liyosha30-glitch/ai-career-platform.git

Navigate to the project:

cd ai-career-platform

Install dependencies:

npm install

Start the development server:

npm run dev

The application will be available at:

http://localhost:5173
